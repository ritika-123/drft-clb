# DRFT CLB — One Page Website

## What is included
- `index.html` — page structure/content
- `style.css` — premium dark/industrial responsive design
- `script.js` — equipment interaction + WhatsApp enquiry form
- `assets/` — place your real logo/photos here

## Before publishing
Replace these placeholders everywhere:
- `+91 99999 99999`
- `919999999999`
- `hello@drftclb.in`
- Google Maps search link
- Founding 100 price if different
- Any wording you want to change

## Free deployment
Recommended: Cloudflare Pages.
1. Create a GitHub repository and upload these files.
2. In Cloudflare Pages, connect the repository.
3. Framework preset: None.
4. Build command: leave blank.
5. Output directory: `/`
6. Deploy.

You can use the free `pages.dev` address initially, so hosting cost can remain ₹0.

## Important
The contact form currently opens WhatsApp; it does not store submissions in a database. This keeps the launch completely free and avoids registration/login.
